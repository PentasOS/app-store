Релизы без карточки

Нажми «Синхронизировать с релизами».

Как добавить новое приложение

  1. Локально одной командой — это основной путь, он сам делает релиз, заливает APK и правит каталог: 
    $env:GH_TOKEN='ghp_...'
C:\cherry\store\add-app.ps1 -Apk "C:\path\App.apk" -Id my-app -Name "My App" -Description "Описание"
  2. Вручную через GitHub — создай релиз и перетащи APK на странице: Открыть «New release» затем здесь нажми «Синхронизировать с релизами» и заполни карточку.

Почему нельзя залить APK прямо из этой страницы: uploads.github.com не отдаёт CORS-заголовки, браузер режет запрос. Это ограничение GitHub, обойти его из JS нельзя.
